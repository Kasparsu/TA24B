## 🗂️ Topics Covered

### 1. 🔢 Types & `var_dump()`

Variables start with `$`, take no keyword, and can hold anything:

```php
$test = 10;                   // int
$test = 3.1;                  // float
$test = 'Hello';              // string
$test = 'õpilane';            // Estonian characters are fine
$test = '💩';                 // so are emoji
$test = true;                 // bool
$test = false;
$test = null;                 // deliberately nothing
$test = [1, true, 'fsas'];    // array: mixed types allowed
$test = new stdClass();       // a generic object
$test->name = 'Kaspar';       // -> reaches a property
var_dump($test);
```

**`var_dump()` is the tool to know.** `echo` prints a value; `var_dump()` prints the value
**and its type** (plus length, for strings). Whenever something behaves strangely, this is how
you find out what you're really holding.

### 2. ➗ Arithmetic

```php
$test = 10 + 10;
$test = 10 - 10;
$test = 10 * 10 * 10;
$test = 10 / 10;
$test = 5 % 2;    // modulo: remainder, 1
$test = 2 ** 3;   // exponent: 2 * 2 * 2 = 8
```

**`%` is remainder, not percent.** `$n % 2` is the standard even/odd test, and `0` means it
divides evenly.

**Compound assignment**: operate on the current value and store it back:
```php
$test = $test + 2;
$test += 2;        // identical, shorter
$test -= 2;
$test *= 2;
$test /= 2;
$test %= 2;
$test **= 2;
```

**Increment / decrement, and why there are two forms:**
```php
$test++;   // post
$test--;
--$test;   // pre

$a = 1;
$b = ++$a;
var_dump($b, $a);   // 2 and 2
```
`++$a` increments **then** returns; `$a++` returns the old value **then** increments. Alone on
a line they're the same; inside a bigger expression they are not.

**Anything more is a function:**
```php
$test = sin($test);
```

### 3. 🔤 Strings

```php
$test = 'hello';
$test = 'hello' . 'world' . '!';   // . joins, not +
$test = $test . '!!!!!';
$test .= '!!!!!';                  // compound form
```

**Interpolation vs concatenation:**
```php
$name = 'Kaspar';
$age  = 33;

$test = $name . ' is ' . $age . ' years old!';
$test = "$name is $age years old!";   // double quotes substitute variables
$test = "hello\n\nworld!";            // and honour escapes like \n
```

| Quotes | Variables | Escapes |
|---|---|---|
| `'single'` | Literal | Only `\'` and `\\` |
| `"double"` | **Interpolated** | `\n`, `\t`, … |

**Heredoc, for multi-line text:**
```php
$test = <<<END
cool stuff here
multi line
END;
var_dump($test);
```
Everything between `<<<END` and the closing `END;` is one string: newlines included, variables
interpolated. Much better than gluing `\n` onto every line.

## ✅ Takeaways

1. **`var_dump()` shows the type, `echo` doesn't.**
2. **`%` is remainder**; `$n % 2` tests even/odd.
3. **`++$a` vs `$a++`** differ the moment you use the result.
4. **`.` joins strings.** Single quotes literal, double quotes interpolate.
5. **Heredoc (`<<<END`)** for multi-line strings.
