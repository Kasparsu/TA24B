### 1. 🔌 Interfaces

```php
interface Logger {
    public function log($message);
}
```

An interface is a **contract**: method names and shapes, no bodies. A class that says
`implements Logger` is promising to provide `log($message)`.

```php
class ConsoleLogger implements Logger {
    public function log($message) { echo "$message\n"; }
}

class NothingLogger implements Logger {
    public function log($message) { /* deliberately silent */ }
}
```

The payoff is in the code that *uses* it:

```php
function doWork(Logger $logger) {
    $logger->log('started');
}
```

`doWork` never learns which logger it got. Swap console for file for silence and the
function is untouched: including implementations written long after it.

Unlike `extends`, a class may implement **several** interfaces.

### 2. 📝 PHP inside HTML

A `.php` file is HTML with holes cut in it:

```php
<h1><?= $title ?></h1>

<?php foreach ($posts as $post): ?>
  <article>
    <h2><?= $post['title'] ?></h2>
  </article>
<?php endforeach; ?>
```

Two habits that make this readable:

- **`<?= ?>`** is shorthand for `<?php echo ?>`. In a template you are almost always
  printing, so use it.
- **The alternative syntax**: `foreach: … endforeach;`, `if: … endif;`, instead of
  braces. When a block spans thirty lines of markup, `endforeach` tells you what just
  ended; a lone `}` does not.

### 3. 🧩 Splitting the Bootstrap blog template into partials

A ready-made Bootstrap blog example was dropped in and immediately cut into `partials/`:
header, nav, posts, sidebar, footer: each pulled in with:

```php
<?php include __DIR__ . '/partials/header.php'; ?>
```

`__DIR__` is the folder of the file doing the including, so the path works no matter which
directory the script was started from.

Why use someone else's design at all? Because on the back end the markup usually arrives
from a designer or a template, and **reading unfamiliar markup is the skill that matters**
far more than writing CSS from scratch.

> 🧠 Same instinct as moving repeated code into a function: say it once, and keep each
> piece small enough to hold in your head.

Examples: <https://getbootstrap.com/docs/5.3/examples/>

## ✅ Takeaways

1. **An interface is a contract.** Type-hint it and implementations become swappable.
2. **A class can implement many interfaces**, but extend only one parent.
3. **`<?= ?>` in templates**, and the `endforeach` / `endif` syntax for long blocks.
4. **`__DIR__`** makes includes independent of the working directory.
5. **Split long templates into partials**: one file per section.
6. **Reading someone else's markup is the real back-end skill.**
