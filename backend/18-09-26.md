## 🗂️ Topics Covered

### 1. 🧵 Traits

Inheritance gives a class **one** parent. When unrelated classes need the same behaviour, a
**trait** is the tool:

```php
trait HasColor {
    public $color;
    public function setColor($color) {
        $this->color = $color;
    }
}

trait HasSmell {
    public $smell;
    public function setSmell($smell) {
        $this->smell = $smell;
    }
}

class Box {
    use HasColor, HasSmell;   // several at once
}

class Something {
    use HasColor;
}
```

A trait is a block of properties and methods **pasted into** whichever class `use`s it. Unlike
`extends`, you can `use` **as many as you like**.

> 💡 Rule of thumb: `extends` for "is a kind of", traits for "can also do this".

### 2. ✨ Magic Methods

Methods whose names begin with `__` are **magic** — PHP calls them for you when something
particular happens.

```php
class Box {
    public function __construct(public int $width, private int $height, protected int $length) {
        var_dump('Box was created');
    }

    public function __set($name, $value) { var_dump($name, $value); }
    public function __get($name)         { var_dump($name); return 'Some value'; }
    public function __call($name, $args) { var_dump($name, $args); }
    public function __invoke($a, $b)     { var_dump($a, $b); }
    public function __toString()         { return 'Im a Box whoopty doo!'; }
    public function __destruct()         { var_dump('Box was Destroyed'); }
}
```

**`__construct` first.** It runs automatically on `new`, and the parameter list does
**constructor property promotion** — `public int $width` as a *parameter* declares the
property, sets its visibility and type, and assigns it, all at once.

| Magic method | Fires when… | Shown by |
|---|---|---|
| `__construct` | The object is created | `new Box(1, 2, 3)` |
| `__set` | Writing an inaccessible property | `$box1->hello = 'LOL';` |
| `__get` | Reading an inaccessible property | `var_dump($box1->yolo);` → `'Some value'` |
| `__call` | Calling a method that doesn't exist | `$box1->cool(1, 'asdads', 41);` |
| `__invoke` | Calling the **object itself** | `$box1(1, 'asdads');` |
| `__toString` | Using the object as a string | `echo $box1;` |
| `__destruct` | The object is destroyed | see below |

**`__destruct` and object lifetime:**
```php
function test() {
    $box2 = new Box(1, 2, 3);
}
test();            // created, then destroyed as the function ends

$box1 = new Box(1, 2, 3);
$box1 = 1;         // nothing refers to the Box any more → destroyed
var_dump($box1);   // int(1)
```

An object is destroyed when nothing points at it any more — when it goes out of scope, or when
the last variable holding it is reassigned.

### 3. 🏛️ `static`

A `static` member belongs to the **class**, not to any object:

```php
class Box {
    public static $count;

    public function volume() {

    }

    public static function test() {
        var_dump(self::$count);
        var_dump(self::class);
        var_dump(static::class);
    }
}

class MetalBox extends Box {
}

Box::$count = 1;
Box::$count = 2;
MetalBox::test();
var_dump(Box::$count);
```

**Reached with `::` rather than `->`,** because there's no object involved. `$count` is shared:
set it through `Box::` and every instance and subclass sees the same value.

**`self` vs `static`:**

| | Resolves to |
|---|---|
| `self::class` | The class where the code was **written** — always `Box` |
| `static::class` | The class it was actually **called on** — here `MetalBox` |

So `MetalBox::test()` prints `Box` then `MetalBox`. That difference is exactly why both
keywords exist.

## ✅ Takeaways

1. **Traits share behaviour across unrelated classes**, and you can use several — unlike
   `extends`.
2. **`__construct(public int $width)`** declares, types, sets visibility and assigns in one go.
3. **Magic methods fire on events** — missing property, missing method, string conversion,
   destruction.
4. **An object dies when nothing refers to it** — scope end or reassignment.
5. **`static` belongs to the class**, reached with `::`. `self::` is where it was written,
   `static::` is what it was called on.
