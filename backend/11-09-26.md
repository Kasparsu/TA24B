## 🗂️ Topics Covered

### 1. 🧩 Functions

```php
function hello(): void {
    var_dump('Hello');
}

var_dump(hello());   // NULL — printed something, returned nothing
hello();
hello();
```

**`: void`** is the return type. `var_dump(hello())` makes the point plainly: **printing and
returning are different things.**

**Parameters with defaults:**
```php
function helloName($name = 'Nameless', $age = 0) {
    var_dump("Hello, $name! You are $age years old!");
}

helloName('Kaspar', 35);
helloName('Martin', 33);
helloName();            // both defaults used
```
Arguments match **by position**; a default makes one optional.

**Returning, with types:**
```php
function square(int $a): int|null {
    if ($a < 0) {
        return null;
    }
    return $a * $a;
    var_dump('YLOLOYLYOLYLO');   // never runs
}

$answer = square(-4);   // null
$answer = square(4);    // 16
var_dump($answer);
var_dump(square(5));
```

| Feature | Meaning |
|---|---|
| `int $a` | Typed parameter — PHP rejects the wrong type |
| `: int\|null` | **Union return type** — an int *or* null |
| early `return null` | Leaves immediately |
| the last `var_dump` | **Unreachable.** Nothing after `return` runs. |

### 2. 🔀 `if` / `else if` / `switch`

```php
$num = 10;

if ($num > 5) {
    var_dump('Bigger');
} else if ($num < 5) {
    var_dump('Smaller');
} else {
    var_dump('Equal');
}
```

Conditions are checked top to bottom; the first true one wins, and `else` catches the rest.

**A real example — which day is it:**
```php
$day = (int) date('w');
var_dump($day);

if ($day === 0) {
    var_dump('Sunday');
} else if ($day === 1) {
    var_dump('Monday');
} else if ($day === 5 || $day === 6) {
    var_dump('Partyday');
} else {
    var_dump('Weirdday');
}
```

**`date('w')` returns the weekday as a *string***, so `(int)` casts it to a number — otherwise
`=== 0` would be false against `'0'`. That's the strict-comparison rule doing its job.

**The same thing as a `switch`:**
```php
switch ($day) {
    case 0:
        var_dump('Sunday');
        break;
    // …
    case 5:
    case 6:
        var_dump('Partyday');
        break;
    default:
        var_dump('Weirdday');
}
```

`case 5:` and `case 6:` stacked with nothing between them is **deliberate fall-through** — both
run the same block. **`break` is what stops execution**; forget it elsewhere and PHP runs on
into the next case, which is the classic `switch` bug.

> 💡 `switch` suits "one value, many specific options". A chain of `else if` suits ranges and
> compound conditions.

### 3. 🔁 `for` and `while`

```php
for ($i = 0; $i < 10; $i++) { var_dump($i); }    // counting up
for ($i = 9; $i >= 0; $i--) { var_dump($i); }    // counting down
for ($i = 1; $i < 1_000_000; $i *= 2) { … }      // doubling
```

Three parts separated by semicolons:

1. **Start** — runs once
2. **Condition** — checked before each pass; loop continues while true
3. **Step** — runs after each pass

The step is just an expression, so `*= 2` is as valid as `++`. `1_000_000` uses underscores as
digit separators purely for readability — PHP ignores them.

**`while` — repeat while something holds:**
```php
$time = time();
$count = 0;
while ($time + 1 > time()) {
    $count++;
}
var_dump($count);
```

Count how many iterations fit in one second. The answer is far larger than people guess, which
is a useful gut-feel for how fast this all really is.

## ✅ Takeaways

1. **Printing is not returning.** A `void` function gives back `NULL`.
2. **Nothing after `return` runs.**
3. **`date()` gives a string** — cast with `(int)` before comparing with `===`.
4. **`switch` needs `break`**; stacked cases are the deliberate exception.
5. **`for` is start; condition; step**, and the step can be anything.
