## 🗂️ Topics Covered

### 1. ⏳ `do…while`

```php
while (false) {
    var_dump('WHILE');   // never runs
}

do {
    var_dump('DO');      // runs once, then checks
} while (false);
```

**`while` tests before the body, `do…while` tests after**, so a `do…while` body always runs
**at least once**.

### 2. 🍎 `foreach`

Three ways to walk an array, from clumsy to idiomatic:

```php
$fruits = ['Apple', 'Cherry', 'Pear', 'Banana'];

for ($i = 0; $i < count($fruits); $i++) {   // manual index
    $fruit = $fruits[$i];
    var_dump($fruit);
}

foreach ($fruits as $fruit) {               // idiomatic
    var_dump($fruit);
}

foreach ($fruits as $key => $fruit) {       // when you need the key too
    var_dump($key, $fruit);
}
```

The `for` version works but makes you manage the index, `count()`, and the off-by-one risk
yourself. **`foreach` can't run off the end.** With `as $key => $value` it gives you the index
for a list, or the string key for an associative array.

### 3. 🔄 Recursion

```php
function recursive($i) {
    if ($i < 10) {
        var_dump($i);
        recursive($i + 1);
    }
}

recursive(0);
```

A function that calls itself. Each call gets its own `$i`, one higher than the last, and the
chain unwinds when the condition finally fails.

> ⚠️ The `if` is the **base case** and it is not optional. Without a path where the function
> *doesn't* call itself, it recurses until PHP runs out of stack.

### 4. 📦 Classes & Objects

```php
class Box {
    public $width;
    public $height;
    public $length;

    public function volume() {
        return $this->width * $this->height * $this->length;
    }
}
```

A **class** is a template; an **object** is a thing built from it. Properties are its
variables, methods its functions, `$this` is the object the method was called on, and `->`
reaches inside.

```php
$box1 = new Box();
$box1->width = 1; $box1->height = 2; $box1->length = 3;
var_dump($box1, $box1->volume());   // 6

$box2 = new Box();
$box2->width = 3; $box2->height = 4; $box2->length = 5;
var_dump($box2, $box2->volume());   // 60
var_dump($box1, $box1->volume());   // still 6: untouched
```

One class, two fully independent objects. `volume()` works on whichever object it was called
on, because `$this` refers to that one.

### 5. 🔗 References and `clone`

```php
$num1 = 1;
$num2 = &$num1;
$num1 = 2;
var_dump($num1, $num2);   // 2 and 2
```

`&` makes **two names for one value**. Change one, the other changes.

**Objects do that by default**, which is why `clone` exists:

```php
$box2 = clone $box1;
$box2->width = $box1->width;
$box1->width = 2;
var_dump($box1, $box2);   // genuinely separate
```

Plain `$box2 = $box1` would leave you with two names for *one* box. Scalars copy on
assignment; objects don't.

### 6. 👪 Inheritance

```php
class MetalBox extends Box {
    public $weightPerUnit;

    public function mass() {
        return $this->volume() * $this->weightPerUnit;
    }
}

$metal1 = new MetalBox();
var_dump($metal1);
```

`MetalBox` gets everything from `Box` and adds its own. Note `mass()` calling
`$this->volume()`: an inherited method used as if it were its own.

### 7. 🔒 Visibility: `public`, `private`, `protected`

```php
class Box {
    public int $width;
    private int $height;
    protected int $length;

    public function setHeight(int $height) {
        if ($height < 0) {
            $this->height = 0;
        } else {
            $this->height = $height;
        }
    }

    public function getHeight() {
        return $this->height;
    }

    public function test1() {
        $this->length = 10;        // protected: fine here
        var_dump($this->length);
    }

    public function test2() {
        $this->height = 10;        // private: fine inside Box
        var_dump($this->height);
    }
}
```

| Keyword | Reachable from |
|---|---|
| `public` | Anywhere |
| `private` | **Only this class** |
| `protected` | This class **and its subclasses** |

Properties are **typed** here too (`public int $width`), same as parameters.

**Why hide anything?** Because then you control how it changes. `$height` is private, so the
only way in is `setHeight()`, which **clamps a negative value to 0**. A public property can be
set to nonsense by anyone; a private one with a setter cannot. That pair of methods is the
classic **getter/setter**.

**The experiment at the end** (calling `$box1->test1()` and then `$metal1->test2()`) is what
makes the difference concrete: a subclass can reach `protected`, but **not `private`**.

## ✅ Takeaways

1. **`do…while` always runs at least once.**
2. **`foreach` beats a manual index**: no `count()`, no off-by-one.
3. **Recursion needs a base case.**
4. **Each object holds its own properties**; `$this` is the one you called.
5. **`&` shares, `clone` separates.** Objects share by default.
6. **`extends` inherits everything non-private.**
7. **private = this class, protected = this class + children.** Getters and setters let you
   validate.
