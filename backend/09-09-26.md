## 🗂️ Topics Covered

### 1. 📚 Arrays

Two ways to write one — the second is what you should use:

```php
$numbers = array(1, 2, 3);   // old syntax, still valid
$numbers = [1, 2, 3];        // modern
```

**Reading and writing by index** (counting from 0):
```php
var_dump($numbers[1]);   // 2
$numbers[2] = 5;
var_dump($numbers);
```

**Mixed types, and nesting:**
```php
$test = [1, 'sasd', true, [1, 2, 3]];
var_dump($test[3][1]);   // 2 — index twice
```
An array can hold anything, including other arrays. The first index picks the inner array, the
second picks inside it.

---

### 2. 🔑 Associative Arrays

Keys can be strings instead of numbers, and the two mix freely:

```php
$test = [
    'name'  => 'Kaspar',
    'age'   => 33,
    1,
    2,
    3,
    'color' => 'green',
    'music' => 'punk',
    5,
    100 => 6,
    7,
];
var_dump($test);
var_dump($test['name']);   // reached by name, not position
```

**Watch what the automatic numbering does.** Unkeyed items get the next free integer — and
after an explicit `100 => 6`, the following item becomes `101`. `var_dump()` on the whole array
is the only sane way to see what you actually built.

### 3. 🛠️ Array Operations

**Joining two arrays with `+`:**
```php
$combined = [1, 2, 3] + [4, 5, 6, 7];
var_dump($combined);   // [1, 2, 3, 7]
```

> ⚠️ **This is not what most people expect.** The `+` operator is a **union by key**, not a
> concatenation. Keys `0,1,2` already exist on the left, so the right-hand values for those
> keys are discarded — only key `3` (`7`) survives. If you want everything appended, that's
> **`array_merge()`**.

| Link | What it is |
|---|---|
| <https://www.php.net/manual/en/function.array-merge.php> | `array_merge()` — what you usually actually want |

**Array to string:**
```php
$text = implode('-', $test);
var_dump($text);
```
`implode()` glues the elements together with a separator. (`explode()` does the reverse.)

**Adding and removing:**
```php
array_push($test, 67, 'asdasd', 322);   // append several at once
$test[] = 'value';                      // shorthand for appending one
unset($test[100]);                      // remove that key entirely
var_dump($test);
```

`unset()` removes the key. It does **not** renumber what's left, so the array keeps a gap —
fine, but surprising if you assumed indexes stay contiguous.

## ✅ Takeaways

1. **Use `[]`, not `array()`.**
2. **Index twice for nested arrays** — `$test[3][1]`.
3. **Named and numbered keys coexist**, and an explicit numeric key moves where automatic
   numbering continues.
4. **`+` on arrays is a union by key, not a concatenation.** Use `array_merge()`.
5. **`implode()` turns an array into a string.**
6. **`unset()` leaves a gap** rather than renumbering.
